## Load-bearing decisions (changing any of these requires re-threat-model)

1. **Two-secret model** (1Password-style: master password + 128-bit secret_key). UPGRADED from initial single-secret draft based on `crypto-auditor` research. Operator should explicitly review REQ-CRYPTO-003 and confirm or veto before Phase 02 begins.
2. E2E client-side encryption with XChaCha20-Poly1305 + Argon2id (OWASP 2024 params, calibrated to 750 ms).
3. BIP-39 24-word recovery phrase, no server-side recovery.
4. WebAuthn + TOTP 2FA, mandatory before vault sharing.
5. HMAC hash-chain audit log + Ed25519-signed daily Merkle checkpoints off-machine.
6. Self-hosted Docker + VPS with Caddy reverse proxy.
7. Drizzle ORM (SQL-first, auditable queries).
8. TipTap rich-text editor with strict schema, no images/tables in v1.
9. Unanimous deletion with 30d timeout + 7d notice + owner override.
10. Per-user X25519 sealed-box key wrapping for shared vaults.
