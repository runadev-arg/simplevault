<objective>
Build the operator CLI with two subcommands:
1. `invite create --email <addr>` — issues an invite code (HMAC-bound, single-use, 7-day TTL), writes to DB, prints the raw code to stdout for the operator to deliver out-of-band.
2. `argon2 calibrate` — runs the Phase 02 calibrator on the local hardware (intended target: Dokploy VPS) and prints the recommended params for the operator to set as Dokploy env vars.

Both subcommands ship in one binary so the operator has a single entry point. Image-side: this CLI is bundled into the `apps/api` Docker image (Phase 01 Plan 06 set up `pnpm deploy` for this purpose) per REQ-INFRA-004.

#!/usr/bin/env node
import { Command } from "commander";
import { inviteCreate } from "./commands/invite-create.js";

const program = new Command();
program.name("simplevault-cli");
program.command("invite create")
  .requiredOption("--email <email>")

`apps/cli/src/lib/hmac.ts`: HMAC-SHA256 of the raw code bytes using `SERVER_INVITE_SECRET` (read from env; fail-fast if missing or shorter than 32 bytes).

`apps/cli/src/commands/invite-create.ts`:
1. Read `DATABASE_URL` + `SERVER_INVITE_SECRET` env; fail-fast on either missing.
2. Lowercase + trim email; validate basic shape (`/^[^\s@]+@[^\s@]+\.[^\s@]+$/` — Zod is fine too).
3. Generate 16 random bytes via `node:crypto.randomBytes(16)`.
4. Encode to a human-friendly format: base32 (Crockford) without padding, hyphenate every 4 chars → e.g. `K3JM-9PXQ-7T4N-22HS-VR8E-A6YF`.
5. Compute `code_hash = HMAC-SHA256(SERVER_INVITE_SECRET, raw_code_bytes)`.
6. INSERT into `invite_codes` with `email` (lowercased), `code_hash`, `expires_at = now() + INTERVAL '7 days'`, `created_by = NULL` (operator account modelling deferred).
7. Print to stdout exactly (and only) the raw human-readable code, plus the email + expiry on a separate informational line. No pino, no file logging.

Build: `pnpm --filter @simplevault/cli build`. Manual smoke test: `pnpm cli invite create --email test@example.com` (with DB up) → row appears in `invite_codes`, code printed to stdout.
