  <action>
**RED:** Tests:
1. `generateKxKeyPair()` returns `{ publicKey: Uint8Array(32), secretKey: Uint8Array(32) }`.
2. `sealedBoxSeal(plaintext, recipientPub)` returns ciphertext of length `plaintext.length + crypto_box_SEALBYTES`.
3. `sealedBoxOpen(ciphertext, recipientPub, recipientSk)` returns the original plaintext.
4. Wrong recipient_sk → throws.
5. Mutated ciphertext (any byte) → throws.
6. End-to-end with a 32-byte vault_DEK: seal to recipient → open with recipient sk → bytes-equal.

Commit RED.

**GREEN:** Implement using `sodium.crypto_box_seal` / `sodium.crypto_box_seal_open` and `sodium.crypto_kx_keypair` (returns `{ publicKey, privateKey }`; rename `privateKey` → `secretKey` in our API for naming consistency with libsodium docs).

Commit GREEN.

**REFACTOR:** Export through both barrels. Add a comment header on `sealed-box.ts` reminding the reader: **sealed-box does NOT authenticate the sender** (anonymous wrap), which is the desired property for invite/share — but if Phase 07 ever needs sender-authenticated wraps, switch to `crypto_box_easy` with sender + recipient keys.
