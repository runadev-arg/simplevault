2. `decrypt({ ciphertext, nonce, aad }, key)` returns the original plaintext when AAD matches.
3. Decrypt with mutated AAD throws (sodium tag mismatch).
4. Decrypt with mutated ciphertext throws.
5. Decrypt with wrong key throws.
6. Two encrypts of identical plaintext + key + aad produce different ciphertext (random nonces).
7. Nonce uniqueness: 10000 encrypts produce 10000 distinct nonces (probabilistic — not strict equality, but a `Set` size check is fine for the smoke).
8. Key length validation: encrypt rejects keys not exactly 32 bytes with a typed error.

Commit RED.

**GREEN:** Implement `packages/crypto/src/aead.ts` using `sodium.crypto_aead_xchacha20poly1305_ietf_encrypt(plaintext, aad, null, nonce, key)` and the matching `_decrypt`. Generate nonce with `sodium.randombytes_buf(sodium.crypto_aead_xchacha20poly1305_ietf_NPUBBYTES)`.

Type the public API:
```ts
export type AeadCiphertext = { ciphertext: Uint8Array; nonce: Uint8Array };
export function encrypt(plaintext: Uint8Array, key: Uint8Array, aad: Uint8Array): Promise<AeadCiphertext>;
export function decrypt(blob: AeadCiphertext, key: Uint8Array, aad: Uint8Array): Promise<Uint8Array>;
```

AAD is **mandatory** in the type (no optional). At call sites, pass `new Uint8Array(0)` if you really mean no AAD — explicit is better than implicit silent omission.
