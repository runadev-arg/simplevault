**JwtAuthGuard**: a NestJS guard that:
1. Extracts `Authorization: Bearer <token>`.
2. Verifies via JwtService (jose, HS256, JWT_SECRET).
3. On valid: attaches `req.user = { id, sessionId, familyId }` (from JWT claims).
4. On invalid/missing: throws `UnauthorizedException` (which AllExceptionsFilter maps to AUTH_INVALID_CREDENTIALS — uniform).

**`MeService.get(userId)`**:
1. SELECT id, email, created_at, argon2_params FROM users WHERE id = $1.
2. Build response object with EXACTLY those four fields.
3. Validate via `MeResponseSchema.parse(out)` — if any extra field slips in (e.g. due to ORM hydration), the parse throws and AllExceptionsFilter returns SERVER_INTERNAL.

**`MeResponseSchema`** in `packages/shared/src/zod/index.ts`:
```ts
export const MeResponseSchema = z.object({
  id: z.string().uuid(),
  email: z.string().email(),
  createdAt: z.string().datetime(),
  argon2Params: z.object({ memoryKiB: z.number(), iterations: z.number(), parallelism: z.literal(1) }),
}).strict();
export type MeResponse = z.infer<typeof MeResponseSchema>;
```

**`MeController`**: `@UseGuards(JwtAuthGuard) @Get("/me")` returns `MeService.get(req.user.id)`.

Apply rate-limit: 300/user/15min keyed by userId (REQ-RATELIMIT-006).
  </action>
  <verify>
- `curl -H "Authorization: Bearer <validJWT>" http://localhost:3001/me` returns 200 with the four fields and ONLY those four. `jq 'keys' <output>` lists exactly `["argon2Params","createdAt","email","id"]`.
- Without token / with garbage token / with expired token → 401 uniform body.
- Direct DB injection of an extra field on the user row → MeResponseSchema.parse throws; client sees 500 SERVER_INTERNAL (no leak).

**`audit-events.ts`** — the contract Phase 10 reads:
```ts
export const AuditAction = {
  SignupOk: "auth.signup.ok",
  SignupFail: "auth.signup.fail",
  LoginOk: "auth.login.ok",
  LoginFail: "auth.login.fail",
  Logout: "auth.logout",
  RefreshOk: "auth.refresh.ok",
  RefreshFail: "auth.refresh.fail",
  RefreshReuseDetected: "auth.refresh.reuse_detected",
  InviteRedeemOk: "invite.redeem.ok",
  InviteRedeemFail: "invite.redeem.fail",
} as const;

export type AuditEvent = {
  ts: string;        // ISO
  action: typeof AuditAction[keyof typeof AuditAction];
  actorUserId: string | null;
  targetId: string | null;
  outcome: "ok" | "fail";
  reason?: string;   // when outcome=fail; bounded enum, no PII
  ipHash: string;    // hex of HMAC(server_event_secret, ip)
  uaFamily: string;  // bounded enum (Chrome/Firefox/Safari/Edge/Other) — not full UA
  requestId: string;
};

export function emitAuditEvent(logger, ev: AuditEvent): void { logger.info({ audit: ev }, ev.action); }
```

Refactor Plans 07 + 08 services to call `emitAuditEvent` instead of ad-hoc `logger.info`.
