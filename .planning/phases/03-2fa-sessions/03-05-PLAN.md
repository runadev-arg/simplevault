**`SessionService.listForUser(userId, currentSessionId)`** — extends Phase-02's `session.service.ts`:
```ts
async listForUser(userId: string, currentSessionId: string): Promise<SessionListItem[]> {
  const rows = await this.db.db.select({
    id: schema.userSessions.id,
    createdAt: schema.userSessions.createdAt,
    lastUsedAt: schema.userSessions.usedAt, // Phase 02 wrote this only on rotation; for now the most-recent row in the family represents "last seen"
    userAgentFamily: schema.userSessions.userAgentFamily,
    ipHash: schema.userSessions.ipHash,
  }).from(schema.userSessions)
    .where(and(eq(schema.userSessions.userId, userId), isNull(schema.userSessions.revokedAt)));
  return rows.map(r => ({
    id: r.id,
    createdAt: r.createdAt.toISOString(),
    lastUsedAt: r.lastUsedAt ? r.lastUsedAt.toISOString() : r.createdAt.toISOString(),
    current: r.id === currentSessionId,
    userAgentFamily: r.userAgentFamily ?? "unknown",
    ipHashB64Prefix: r.ipHash ? r.ipHash.toString("base64").slice(0, 6) : "",
  })).sort((a, b) => {
    if (a.current !== b.current) return a.current ? -1 : 1;
    return a.createdAt.localeCompare(b.createdAt);
  });
}
```
Note: there will often be MULTIPLE non-revoked rows per family (rotation history that hasn't been cleaned up). Decision: list one row per FAMILY (the latest non-revoked row by `createdAt desc`). Update the SQL: `SELECT DISTINCT ON (family_id) ...` ordered `family_id, createdAt DESC`. Pass `currentSessionId` (which is the actual sid claim from JWT) → if any row of the family matches, that family's representative row is marked current (find the family of `currentSessionId` first, then mark whichever representative belongs to it).

**`SessionService.revokeOne(userId, sessionId)`** — `UPDATE user_sessions SET revoked_at = now() WHERE family_id = (SELECT family_id FROM user_sessions WHERE id = $1 AND user_id = $2) AND revoked_at IS NULL RETURNING id`. Zero rows → return null (controller maps to 404). One+ rows → return `{familyId, revokedCount}`.

**`SessionService.revokeAllForUser(userId)`**:
```ts
async revokeAllForUser(userId: string): Promise<{revokedCount: number}> {
  const result = await this.db.db.execute(sql`UPDATE user_sessions SET revoked_at = now() WHERE user_id = ${userId} AND revoked_at IS NULL RETURNING id`);
  await this.bumpEpoch(userId);  // From Plan 04 — synchronous DB UPDATE + Redis DEL
  return { revokedCount: result.rows.length };
}
```
