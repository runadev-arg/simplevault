# Plan 05-04 — TipTap editor + sanitization

Two focal invariants: schema strictness at parse, sanitize-html at render. Belt-and-suspenders per REQ-WEBSEC-005.

## Tasks

<task type="auto" id="T1">
  <action>
Add TipTap deps + `sanitize-html` to `apps/web/package.json` (use `pnpm add` from the workspace). Pin to current major versions. Do NOT pull `@tiptap/extension-image`, `@tiptap/extension-table`, or any other disallowed extension.

Create `apps/web/src/lib/tiptap/schema.ts` exporting `STRICT_EXTENSIONS: Extension[]`:
- `Document`, `Paragraph`, `Text`, `HardBreak` (allowed), `Heading.configure({levels: [1,2,3]})`, `BulletList`, `OrderedList`, `ListItem`, `Blockquote`, `CodeBlock`
- Marks: `Bold`, `Italic`, `Strike`, `Underline`, `Code`, `Link.configure({openOnClick: false, autolink: true, protocols: ['http', 'https'], validate: (href) => /^https?:\/\//i.test(href), HTMLAttributes: {rel: 'noopener noreferrer', target: '_blank'}})`

JSDoc at the top: "FROZEN v1 schema per REQ-VAULT-008. Adding image/table/embed extensions here = security review required + Phase-bump."
  </action>
</task>

<task type="auto" id="T2">
  <action>
Create `apps/web/src/lib/tiptap/editor.tsx`. Controlled component:
- Props: `{value: JSONContent, onChange: (next: JSONContent) => void, readOnly?: boolean}`.
- Uses `useEditor({extensions: STRICT_EXTENSIONS, content: value, editable: !readOnly, onUpdate: ({editor}) => onChange(editor.getJSON())})`.
- `parseOptions: {preserveWhitespace: false}`.
- Renders `<EditorContent editor={editor} />`.

Create `apps/web/src/lib/tiptap/sanitize.ts`. Export `sanitizeRenderedHtml(html: string): string` with `sanitize-html` config:
- `allowedTags`: only the schema-mirror set (`p`, `h1`, `h2`, `h3`, `ul`, `ol`, `li`, `blockquote`, `pre`, `code`, `strong`, `em`, `s`, `u`, `a`, `br`).
- `allowedAttributes`: `{ a: ['href', 'target', 'rel'], code: ['class'], pre: ['class'] }`.
- `allowedSchemes: ['http', 'https']`. No `data:`, no `javascript:`.
- `transformTags: { 'a': sanitizeHtml.simpleTransform('a', { rel: 'noopener noreferrer', target: '_blank' }) }`.

Export `RenderedTipTapHtml({html}: {html: string})` React component that runs `sanitizeRenderedHtml` then renders via `dangerouslySetInnerHTML={{__html: clean}}` — the ONLY place in the codebase allowed to do so. Use it for the read-only history-diff view. The live editor uses TipTap's React reconciliation directly (no `dangerouslySetInnerHTML`).
  </action>
</task>

<task type="auto" id="T3">
  <action>
Add `apps/web/src/lib/tiptap/sanitize.test.ts` (Vitest):
- `sanitizeRenderedHtml('<a href="javascript:alert(1)">x</a>')` → `<a></a>` or stripped href; in either case no `javascript:` substring in output.
- Same for `data:text/html,...`, `vbscript:...`.
- `<script>alert(1)</script>` → empty.
- `<iframe src="...">` → empty.
- `<img src="x">` → empty (not in v1 schema).
- `<table>` → empty.
- A valid TipTap-emitted HTML snippet (paragraph + bold + link to `https://example.com`) round-trips through sanitize unchanged in semantic terms (link gets `rel`/`target`).

Add `apps/web/src/lib/tiptap/editor.test.tsx` (Vitest + RTL or @vue/test-utils equivalent — match the project's existing pattern):
- Pasting `<script>` into the editor results in TipTap's JSON output containing NO node with `type: "script"` (TipTap drops unknown nodes by default with the strict schema).
- Setting a link href to `javascript:alert(1)` via the link mark API → `validate` rejects → mark not applied.

Run `pnpm --filter @simplevault/web test` and `pnpm -w typecheck`.
  </action>
</task>
