# Plan 07-02 — API: VaultSharingModule

**Wave 2** (after 07-01)

## Goal
The API exposes all endpoints needed for shared vault lifecycle. The server
NEVER sees vault DEKs — it only stores sealed-box ciphertext.

## Endpoints

| Method | Path | Guard | Description |
|--------|------|-------|-------------|
| POST | /vaults/group | JWT + Require2FA | Create shared vault |
| GET | /vaults | JWT + Require2FA | List all vaults (personal + shared) |
| GET | /users/lookup | JWT + Require2FA | Look up user by email → `{id, kxPublicKey}` |
| GET | /vaults/:id/invites | JWT + Require2FA | List pending invites (owner view) |
| POST | /vaults/:id/invites | JWT + Require2FA | Create invite (owner sends sealed wrappedVaultKey) |
| GET | /invites | JWT + Require2FA | List pending invites for current user |
| POST | /invites/:inviteId/accept | JWT + Require2FA | Accept invite (status → active) |
| POST | /invites/:inviteId/decline | JWT + Require2FA | Decline invite (status → revoked) |
| GET | /vaults/:id/members | JWT + Require2FA | List active members |
| DELETE | /vaults/:id/members/:userId | JWT + Require2FA | Remove member (owner) or leave (self) |

## T1 — Shared DTOs in `packages/shared`

**`CreateGroupVaultDto`:**
```ts
{ name: z.string().min(1).max(100), wrappedVaultKey: z.string().min(1) /* base64url */ }
```

**`CreateInviteDto`:**
```ts
{ inviteeId: z.string().uuid(), wrappedVaultKey: z.string().min(1) /* base64url */ }
```

Error codes:
- `E2012 VAULT_NOT_FOUND` — 404 (vault doesn't exist or requester not a member)
- `E2013 VAULT_INVITE_NOT_FOUND` — 404
- `E2014 VAULT_ALREADY_MEMBER` — 409 (user already has an active or pending membership)
- `E2015 VAULT_ACCESS_DENIED` — 403 (operation requires owner role)
- `E2016 VAULT_USER_NOT_FOUND` — 404 (user lookup by email: no such user)

## T2 — `VaultSharingService`

**File:** `apps/api/src/vault-sharing/vault-sharing.service.ts`

Key methods:

```ts
createGroupVault(userId, name, wrappedVaultKeyB64url): Promise<{id, name, kind}>
  - INSERT vaults (kind='shared', name)
  - INSERT vault_memberships (role='owner', status='active', wrappedVaultKey=decode(b64url))
  - RETURN {id, name, kind}

listVaults(userId): Promise<VaultListItem[]>
  - personal: SELECT vaults WHERE owner_user_id=$userId AND kind='personal'
  - shared: SELECT vaults JOIN vault_memberships WHERE user_id=$userId AND status='active'
  - RETURN [{id, name, kind, role, memberCount}]

lookupUser(requesterId, email): Promise<{id, kxPublicKey: string /* base64url */}>
  - SELECT users WHERE lower(email)=lower($email)
  - 404 if not found
  - NEVER return requester's own kxPublicKey (404 same as not found — anti-enumeration)
  - Return {id, kxPublicKey: toBase64url(user.userPubKey)}

createInvite(ownerId, vaultId, inviteeId, wrappedVaultKeyB64url): Promise<MembershipSummary>
  - Verify vault exists AND ownerId has role='owner' AND status='active' → else 403/404
  - Verify inviteeId != ownerId
  - INSERT vault_memberships (role='member', status='pending', wrappedVaultKey)
    ON CONFLICT (vault_id, user_id) DO NOTHING → if exists, return 409 VAULT_ALREADY_MEMBER

getPendingInvitesForUser(userId): Promise<PendingInvite[]>
  - SELECT memberships + vaults WHERE user_id=$userId AND status='pending'
  - Include wrappedVaultKey (base64url) so client can open sealed box

acceptInvite(userId, inviteId): Promise<void>
  - UPDATE vault_memberships SET status='active' WHERE id=$inviteId AND user_id=$userId AND status='pending'
  - 0 rows → 404

declineInvite(userId, inviteId): Promise<void>
  - UPDATE vault_memberships SET status='revoked' WHERE id=$inviteId AND user_id=$userId AND status='pending'
  - 0 rows → 404

listActiveMembers(requesterId, vaultId): Promise<MemberSummary[]>
  - Verify requester is active member → else 404 (anti-enumeration)
  - SELECT memberships + users WHERE vault_id=$vaultId AND status='active'
  - Return [{userId, email, role, joinedAt}]

removeMember(requesterId, vaultId, targetUserId): Promise<void>
  - If requesterId == targetUserId: any active member can leave (self-remove)
  - Else: requester must be owner
  - DELETE FROM vault_memberships WHERE vault_id=$vaultId AND user_id=$targetUserId AND status='active'
  - Owner cannot remove themselves if they're the only member (last-owner guard: SELECT count(*) WHERE role='owner' AND status='active')
```

## T3 — `VaultSharingController` + `VaultSharingModule`

Wire all methods. Apply:
- `@UseGuards(JwtAuthGuard, Require2FAGuard)` on controller class
- Body cap 4 KiB (wrapped vault keys are small)
- Throttler ceilings:
  - `vault-create` 10/user/min
  - `vault-invite` 20/user/min
  - `vault-lookup` 60/user/min

Register `VaultSharingModule` in `AppModule`.
