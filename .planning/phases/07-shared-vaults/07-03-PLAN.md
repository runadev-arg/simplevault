## Goal

## T1 — `apps/web/src/lib/crypto/vault-key.ts`

```ts
import { ready, sealedBoxOpen, sealedBoxSeal } from "@simplevault/crypto/browser";
import sodium from "libsodium-wrappers-sumo";

/**
 * Phase 07 — Vault DEK wrap/unwrap helpers for shared vault key exchange.
 *
 * All operations use X25519 sealed-box (libsodium crypto_box_seal /
 * crypto_box_seal_open). The sealed box is 48 bytes (32-byte key +
 * 16-byte MAC + ephemeral DH overhead = 32+16 = 48 for a 32-byte input).
 *
 * The X25519 public key of each user lives in `users.user_pub_key` and is
 * returned by the API on invite lookups. The private key is unwrapped at
 * login and held in `keyStore.getBytes("kx_sk")`.
 */

/** Generate a fresh 32-byte vault DEK using libsodium's CSPRNG. */
export async function generateVaultDek(): Promise<Uint8Array> {
  await ready();
  return sodium.randombytes_buf(32);
}

/**
 * Seal vault_DEK under a recipient's X25519 public key.
 * Result is a 48-byte sealed box — suitable for storage in
 * `vault_memberships.wrapped_vault_key`.
 */
export async function wrapVaultKey(
  vaultDek: Uint8Array,
  recipientKxPk: Uint8Array,
): Promise<Uint8Array> {
  await ready();
  return sealedBoxSeal(vaultDek, recipientKxPk);
}

/**
 * Open a sealed vault DEK using the recipient's X25519 keypair.
 * Throws if the sealed box is invalid (wrong key or tampered).
 */
export async function unwrapVaultKey(
  sealed: Uint8Array,
  myKxPk: Uint8Array,
  myKxSk: Uint8Array,
): Promise<Uint8Array> {
  await ready();
  return sealedBoxOpen(sealed, myKxPk, myKxSk);
}
```

## T2 — `keyStore` integration note (no code change)

`keyStore` (from `apps/web/src/lib/auth/key-store.ts`) is a generic
`Map<string, Uint8Array>` with `wipe()`. Callers store vault DEKs under
`"vault_dek:${vaultId}"` — no schema change needed in key-store itself.

The callers that SET vault DEKs:
1. **Vault create** (07-04): generates DEK → stores under `vault_dek:${newVaultId}`
2. **Invite accept** (07-05): opens sealed box → stores under `vault_dek:${vaultId}`

The callers that GET vault DEKs:
1. **Credential create/edit** (07-06): reads `vault_dek:${vaultId}` when `vaultId` param present
2. **Vault credential list** (07-04): reads `vault_dek:${vaultId}` for decrypt

No `keyStore` source changes. Document the contract in the file JSDoc.
